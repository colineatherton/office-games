One-time setup needed

This game syncs players through a free Firebase Realtime Database, and the config hasn't been filled in yet.

  1. Go to console.firebase.google.com and create a project.
  2. Build → Realtime Database → Create database → test mode.
  3. Project settings → Your apps → add a Web app.
  4. Copy the config object into firebase-config.js (repo root).

Full walkthrough in the README. Takes about 5 minutes, free, no credit card.
