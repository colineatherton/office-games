🪜 Word Ladder Race

One-time setup needed

This game syncs players through a free Firebase Realtime Database, and the config hasn't been filled in yet.

  1. Go to console.firebase.google.com and create a project.
  2. Build → Realtime Database → Create database → test mode.
  3. Project settings → Your apps → add a Web app.
  4. Copy the config object into firebase-config.js (repo root).

Full walkthrough in the README. Takes about 5 minutes, free, no credit card.

🪜 Word Ladder Race

Room code: ----
How it works: both teams climb from the same start word to the same target, changing one letter per rung (real words only — the dictionary is the referee). Anyone on your team can type the next step; Undo removes your last rung. First to the target scores +20, with +5 for matching par. Hopelessly stuck? If both teams give up, the shortest path is revealed. 3-minute cap per round; the host picks how many rounds.

Click a team to switch sides.
