💬 Quip Duel

One-time setup needed

This game syncs players through a free Firebase Realtime Database, and the config hasn't been filled in yet.

  1. Go to console.firebase.google.com and create a project.
  2. Build → Realtime Database → Create database → test mode.
  3. Project settings → Your apps → add a Web app.
  4. Copy the config object into firebase-config.js (repo root).

Full walkthrough in the README. Takes about 5 minutes, free, no credit card.

💬 Quip Duel

Room code: ----
How it works: every prompt ("a terrible name for a cruise ship…") goes to exactly two players. Both write their funniest answer, then the room votes between them head-to-head. +10 per vote, +30 for a shutout 💥. After the rounds, everyone answers one Grand Final prompt for the podium. Host picks the rounds. Needs 3+ players — funny is mandatory.

📺 Screen-sharing the call? Open the Big Screen and share that window — it shows the face-offs, votes and reveals in cinema size.
