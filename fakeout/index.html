🖼️ Fakeout Gallery

One-time setup needed

This game syncs players through a free Firebase Realtime Database, and the config hasn't been filled in yet.

  1. Go to console.firebase.google.com and create a project.
  2. Build → Realtime Database → Create database → test mode.
  3. Project settings → Your apps → add a Web app.
  4. Copy the config object into firebase-config.js (repo root).

Full walkthrough in the README. Takes about 5 minutes, free, no credit card.

Room code: ----
How it works: everyone secretly draws a different absurd prompt. Each drawing then goes on display: everyone else writes what they think it is (or a title designed to fool the room), then votes on which title is the real one. Find the truth +100, fool someone with your fake +50, and artists earn +50 per person who sees through the chaos. Host picks drawing time and cycles. 📺 Tip: open the Big Screen and screen-share it in the call — it's the party's TV screen.
