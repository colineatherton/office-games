📍 Globetrotter

One-time setup needed

This game syncs players through a free Firebase Realtime Database, and the config hasn't been filled in yet.

  1. Go to console.firebase.google.com and create a project.
  2. Build → Realtime Database → Create database → test mode.
  3. Project settings → Your apps → add a Web app.
  4. Copy the config object into firebase-config.js (repo root).

Full walkthrough in the README. Takes about 5 minutes, free, no credit card.

📍 Globetrotter

Room code: ----
How it works: everyone studies the same mystery location — walk around in Street View, or watch text clues reveal one by one — then drops a pin on the world map before the clock runs out. Scoring is GeoGuessr-style: up to 5,000 points, falling off the further your pin is from the truth. Closest pin gets the 🎯. Highest total after all rounds is the 🌍 Globetrotter. The host picks the mode, difficulty, rounds and timer — on 💀 Hard you're dropped on an anonymous street with the view frozen: no walking, no looking around, no zoom.

Players

    🔑 Add a Google Maps key to unlock Street View mode — see the comments in maps-config.js (repo root). Clue mode needs no key at all.
